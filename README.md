## Windows 装好后怎么远程连接？

这个部分反而很简单。

丽萨主机的官方帮助文档说明，Windows 服务器可以通过 RDP 连接。Windows 本机使用系统自带的远程桌面客户端即可；macOS 用户则可以使用 Microsoft Remote Desktop。独立 IP 机器通常连接 `公网IP:3389`，如果是 NAT 机器，则需要使用映射后的外部端口。用户名为 `Administrator`，密码使用丽萨主机面板里的系统密码。

基本流程就是：

1. 购买明确支持 Windows 的 VPS。
2. 下单时选择 Windows，或按照套餐页面要求提交工单。
3. 等系统安装完成。
4. 从面板拿到公网 IP、端口和系统密码。
5. 在 Windows/macOS 上打开远程桌面客户端。
6. 使用 `Administrator` 登录。

需要特别注意的是 **3389 并不是所有机器都能直接暴露出来**。如果机器属于 NAT 架构，需要先确认端口映射；官方文档也把独立 IP 与 NAT 两种连接方式区分开了。

## 购买前最后检查这几件事

### 先看具体套餐，而不是只看产品线

“美国 9929 支持 Windows”不代表所有网站历史套餐都支持。当前官网就存在明确“不支持 Windows”的 CERA 产品示例。

### 再看内存，不要只看价格

丽萨主机自己已经提示 Windows 建议至少 2G。尤其 399 元年付这种低价方案，看起来很便宜，但 1G 内存和 2G 内存对应的是不同使用场景。

### 再看带宽和流量是否匹配

“200Mbps 不限流量”和“500Mbps 8TB”不是谁绝对更强，而是两种资源结构。

不限流量版本特别适合持续传输，但具体带宽仍然有上限；固定流量版则更适合明确知道每月大概需要多少数据的人。美国 4837 和 9929 的不同档位就是很典型的例子。

### 最后再看 IP 属性

如果你的应用真的依赖“住宅 IP”“原生 IP”“双 ISP”等属性，建议把 IP 当作购买条件的一部分，而不是把 Windows 当成唯一筛选条件。社区对于部分产品的住宅 IP 定义确实存在争议，这一点值得提前知道。
